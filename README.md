# Seleção e Agrupamento de Dados com Pandas

Este notebook Jupyter apresenta técnicas essenciais para a manipulação, filtragem e análise agregada de dados utilizando a biblioteca **Pandas** em Python.

## 📋 Conteúdo do Notebook

O projeto está estruturado para cobrir as seguintes etapas de análise de dados:

* **Introdução ao Pandas**: Configuração inicial e carregamento de dados.
* **Seleção de Dados**: Métodos para filtrar colunas e linhas específicas, utilizando indexação avançada.
* **Agrupamento (Groupby)**: Técnicas para agrupar dados por categorias e aplicar funções de agregação (soma, média, contagem).
* **Criação de Novas Variáveis**: Demonstração de como criar colunas calculadas (ex: cálculo de emissão *per capita*).
* **Visualização de Dados**: Uso da biblioteca **Plotly Express** para criar gráficos interativos (dispersão e barras) que ajudam a interpretar os dados agrupados.

## 🛠️ Tecnologias Utilizadas

* **Python 3**: Linguagem base do projeto.
* **Pandas**: Principal ferramenta para manipulação de DataFrames.
* **Plotly Express**: Biblioteca para visualizações gráficas interativas e dinâmicas.
